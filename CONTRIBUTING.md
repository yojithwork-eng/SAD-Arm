# Contributing

SAD is a collaborative student engineering project. Agree on responsibility before changing shared wiring, mechanics, or code.

1. Open an Issue and describe the intended change or measurement.
2. Check battery, wiring and mechanism safety with power disconnected.
3. Record the specific tested pinout and power configuration.
4. Save actual Arduino code with a clear commit message; label generated examples as untested.
5. Add a dated build log with goal, procedure, measurements, observed results, root cause, evidence, and next step.
6. Review with teammates before publishing or making a potentially hazardous system change.
7. Close Issues only after the acceptance criteria have physical evidence.

Do not post teammate personal data, private photos, credentials, or unreviewed battery wiring publicly.
